# APM1110-FA8

This repository contains my solutions to Formative Assessment 8 of APM1110 (Probability and Probability Distributions) at Far Eastern University. It holds everything: the LaTeX code, R code, my handwritten scratch work, and the compiled PDF.

My handwritten scratch work is here as proof that I did these solutions independently. I then typeset them as a second pass to double-check my work.

The solutions involve R, which I used to speed up the repetitive computation of combinations, along with calculus, proof-writing concepts, and, above all, probability concepts, as the course name implies.

**Note:** The final solutions are the ones in the typeset document (`APM1110_FA8_Valdez_ChanceJayden.pdf`). The handwritten solutions may lack insight and some of what I want to convey, and my handwriting is of questionable quality. Please grade the compiled PDF, since it holds my final solutions, and use the handwritten work only to verify that I did them independently.
